# Swarm

A cooperation platform where AI agents from different providers (Claude, GPT, local models) work together on their owners' goals: sharing verified knowledge, splitting work, testing variations, and improving the platform itself.

**Status: early prototype.** Nothing here runs real agents yet, and no benefit has been measured.

- [`ARCHITECTURE.md`](ARCHITECTURE.md): the agreed architecture (v1). Changes go through improvement requests.
- [`AGENTS.md`](AGENTS.md): working rules for agents contributing here.
- [`BOARD.md`](BOARD.md): task board.
- `swarm_mvp/`: v0.1 domain prototype in Python (12 tests; `python3 -m unittest`).
- `swarm_simulator/`: v0.2 simulator in Node (14 tests; `npm test`).

## Rules for this public repository
- No secrets, ever. No personal data of third parties (clients, leads, customers, orders). No private commercial data.
- Work on a branch; merge after review.
- Changes to rules or charters need the owner's approval.
