# FONT-PE-R5-QA — independent review of Claude r5

Date: 2026-10-30. Reviewer role: GPT. Scope: actual FB-001 r5 fonts produced by
Claude, compared against the existing Oron 0.935 Regular/Bold release. This is not
self-review of GPT's qof prototype. Rubric v1 is unchanged; no total score assigned.

## Verdict

Pass for isolation and tested technical compatibility. No obvious new small-text
regression observed in these samples. This is a scoped review, not unrestricted
release approval or a 10/10 typography verdict. Integration and benchmark comparison
remain pending. The canonical shared board records owner acceptance of r5's design;
that acceptance does not cover the whole family, pending numerals or the qof trial.

## Evidence and checks

Downloaded both actual TTFs and three source files from Claude's private r5 snapshot;
all five SHA-256 entries match its manifest. Both fonts decode and rasterize. Exact
outline comparison finds only pe/finalpe changed, out of 60 glyphs. Glyph order is
identical. Coverage, all horizontal metrics, GPOS and other present layout tables,
OS/2/hhea and global hinting tables are byte-identical. Glyph instructions differ
only for the two edited glyphs, consistent with the regenerated hinted outlines.

Implemented `compare_release.py`: read-only checks against an explicit allowed glyph
set, source-byte pins, protected table comparison and a report of glyph instruction
changes. It rejects no-op candidates, unknown allowed names, unauthorized outlines
and protected table changes. It does not prove visual quality or source reproducibility.

Ten checks on actual files passed: accepted intended changes, omitted finalpe
allowance rejected, no-op rejected, injected unrelated advance regression rejected,
and injected unrelated outline regression rejected, each in Regular and Bold.
12 existing Python tests pass; compile and whitespace checks pass on Linux Python
3.12. Mac Python 3.9/3.13 and a new full build were not available in this review.

## Visual observations

Matched actual hinted before/after sheet inspected at 12, 16, 24, 32, 48 and 96ppem,
using Pillow RAQM. Enlarged pe/finalpe show the revised continuous top-to-nose curl
and the more vertical terminal cut. The r5 Bold counter remains compact; the smallest
sizes do not establish a clear improvement over baseline. No claim of Polin equivalence:
its authorized locally installed binary is unavailable here and no fallback was used.
The private sheet preserves sample/alphabet/digits/sentences ordering.

## Build and integration prerequisite

The r5 wrapper explicitly expects an isolated trial workspace. It calls the original
build, which writes that workspace's `output/nine/curve-v2`, before copying renamed
trial fonts. Its preview generator also uses project-relative output paths. Do not
run this wrapper as a drop-in command in the canonical workspace merely because its
docstring says nothing canonical is written. This is a usage prerequisite, not proof
that Claude modified the real canonical release. It was not executed in this review.

Next: one integrating writer reproduces r5 in the established isolated environment,
checks private sources and applies it as a new release candidate with matched Polin
and text-size evidence. Preserve current release and both prior rejected revisions.
No canonical source/output changed by this review; no merge performed.

## Knowledge reuse and limits

Reuses the baseline audit and previous glyph-isolation lesson: typography changes
must be reviewed on actual fonts, not merely source patches or passing tests. This
review extends the check to layout and global hinting tables, then visually inspects
the real fonts. Claude's later numeral trial is separate and not approved here.

Both account dashboards were unavailable; the daily capacity denominator and project
attribution remain unknown. This was one bounded implementation/review batch.
